# Suno Create Assistant

[Suno Create](https://suno.com/create) のアドバンストタブ向けローカルChrome拡張です。保存済みスタイルへの素早いアクセス、独自マスタリングプロンプト、再利用可能な詳細オプションプリセット、曲名の自動設定を追加します。

## ローカルへの導入

1. `pnpm install` で依存関係をインストールします。
2. `pnpm build` で拡張をビルドします。
3. `chrome://extensions` を開き、**デベロッパーモード**を有効にして、**パッケージ化されていない拡張機能を読み込む**から `output/chrome-mv3` を選択します。
4. `https://suno.com/create` を開き、**アドバンスト**タブを選択します。

## 使い方

### スタイルとマスタリング

スタイルプルダウンは、**スタイル** の見出し直下に表示されるため、スタイルセクションの開閉状態に関わらず常に見えます。保存済みSunoスタイルと任意のマスタリングプロンプトを選択すると、拡張は両方を別の行としてスタイル欄へ入力します。**管理…** から画面内ダイアログを開くと、マスタリングプロンプトの追加・編集・削除ができます。

拡張はSuno標準ダイアログから各保存スタイルのプロンプト本文だけを読み取り、永続保存しません。スタイル名は一覧のラベルに使われ、保存日はスタイル欄へ入力されません。Sunoの保存スタイル一覧を開く・変更した後は、次に拡張のプルダウンを開いた時点でメモリ上の一覧を更新します。

スタイルとマスタリングを合わせてSunoの1,000文字制限を超える場合は、何も変更せずエラーを表示します。

### 詳細オプションのプリセット

プリセットプルダウンは、**その他のオプション** の見出し直下（開閉するパネル本文の手前）に表示されるため、パネルの開閉状態に関わらず常に見えます。スタイル除外、ボーカル性別、長さ、Maxモード、奇抜さ、スタイルの影響、バリエーション、パーソナライズのすべて、または選んだ項目だけを保存できます。

プルダウン右隣の **設定を保存** ボタンを押すと、Sunoの現在値を取り込んだプリセット作成ダイアログが開きます。スタイル除外、ボーカル性別、長さ、Maxモード、奇抜さ、スタイルの影響、バリエーション、パーソナライズから保存したい項目を選び、値を編集して保存してください。その他のオプションが閉じていても設定を取得できます。また、プルダウン内の **プリセットを管理…** から既存プリセットの編集や削除が行えます。適用時には、保存された設定だけが変更されます。

### 曲名の自動設定とテイク番号（{{TAKE}}）

曲名セクション内の **自動設定** を有効にすると、設定されたフォーマットに従って曲名を生成します。初期値は次の形式です。

```text
{{WORKSPACE}} ({{STYLE}}) {{TAKE}}
```

- 設定ダイアログの「曲名フォーマット」から任意の書式に変更できます。
  - `{{WORKSPACE}}`: 保存先（ワークスペース名）
  - `{{STYLE}}`: スタイル名（選択スタイル名、手動編集時は `カスタム`）
  - `{{TAKE}}`: テイク番号
- 曲名に `{{TAKE}}` が含まれている場合、**作成ボタンのクリック** または **ショートカット押下** 時に、現在の曲名（`{{TAKE}}` を除いたキー）に対応するテイク番号をローカルストレージでカウントアップし、テイク番号（1, 2, 3...）を入力してサブミットします。
- 送信後、曲名欄は即座に元の `{{TAKE}}` 入りテンプレートへ戻るため、続けて次のテイクを作成できます。
- 自動設定をオフにして手動で `My Song {{TAKE}}` と入力した場合でも同様にテイク番号がカウントアップされます。

### 作成ショートカットとひらめき表示

Suno作成画面では、設定不要で `Cmd + Enter`（Mac） / `Ctrl + Enter`（Windows/Linux）を押すと「作成」ボタンを実行できます（曲名に `{{TAKE}}` があればテイク番号採番・復元も行われます）。また、操作行が折り返さないよう、Sunoの **インスピレーション** ボタンの表示を **ひらめき** に短縮します。

### サイドバー「拡張設定」メニュー

サイドバーのナビゲーション（Hooksの下・プロフィールの手前）に、歯車アイコン付きの **拡張設定** メニューを追加します。クリックするとSuno画面内の設定ダイアログが開き、曲名フォーマット、マスタリングプロンプト、プリセットを一括管理できます。設定ダイアログが開いている間はメニューがアクティブ表示になります。また、サイドバーを最小化・折りたたんだ場合でも、Suno標準メニューと同様に文字が自動的に非表示になり歯車アイコンだけが綺麗に残るよう連動します。

### ディスクロージャの初期折りたたみ（表示設定）

アドバンスドタブを開いた際に、「歌詞」「スタイル」「その他のオプション」の各入力セクション（アコーディオン）を閉じた状態をデフォルトにします。拡張機能のプルダウンUI（スタイル・マスタリング・プリセット）は見出し行に常に表示されているため、画面をすっきりと保ったまま素早く操作できます。

設定ダイアログ（サイドバーの「拡張設定」など）の「表示設定」にある **「アドバンスドタブを開いた時に歌詞、スタイル、その他のオプションを閉じる」** チェックボックスから、この自動折りたたみ動作の有効／無効を切り替えられます（初期状態はON）。自動で閉じた後、個別のセクションを手動でクリックして開いた場合は、編集・入力中に勝手に再度閉じられることはありません。

## プライバシー

マスタリングプロンプト、プリセット、自動設定状態、曲名フォーマット、テイク番号の記録はすべてChrome拡張のローカルストレージに保存されます。Sunoの非公開APIは使わず、サーバーへのデータ送信や、Suno保存スタイルプロンプトの永続保存も行いません。
