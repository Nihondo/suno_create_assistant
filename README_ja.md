# Suno Create Assistant

[Suno Create](https://suno.com/create) のアドバンストタブ向けローカルChrome拡張です。保存済みスタイルへの素早いアクセス、独自マスタリングプロンプト、再利用可能な詳細オプションプリセット、曲名の自動設定を追加します。Sunoの言語設定（英語・日本語）を自動検知して完全対応しています。

## インストール手順

本リポジトリにはビルド済みの拡張機能（`install/chrome-mv3`）が含まれているため、Node.js やビルドツールの環境構築なしですぐに利用できます。

1. 本リポジトリのコードをダウンロード（**Code** → **Download ZIP**）して解凍、または `git clone https://github.com/Nihondo/suno_extension.git` します。
2. Google Chrome で `chrome://extensions` を開き、右上の **デベロッパーモード** を有効にします。
3. **パッケージ化されていない拡張機能を読み込む** をクリックし、リポジトリ内の `install/chrome-mv3` フォルダを選択します。
4. [Suno Create](https://suno.com/create) を開き、**アドバンスト** タブを選択すると機能が有効になります。

## 使い方

[Create/Advancedタブ](images/suno_create.png)

### 多言語対応（日本語・英語）

Sunoの言語設定（`en` または `ja`）を自動的に判別します。Suno本体の各要素（Styles、More Options、スライダー、トグル、保存スタイルダイアログなど）が英語・日本語のどちらでも問題なく動作し、拡張機能自身のUI（プルダウン、ボタン、通知メッセージ、設定ダイアログ）もSunoの言語に合わせて自動で切り替わります。

### 歌詞タグパレット

**Lyrics**（歌詞）の見出し直下に、角丸矩形のボタン（`Instrumental`, `Intro`, `Verse 1`, `Chorus` など）が並ぶタグパレットを表示します。楽曲構成タグ（メタタグ）をワンクリックで歌詞欄へ挿入できます。

- **ワンクリックで挿入**: タグボタンをクリックすると、角括弧付きのタグ（例: `[Verse 1]`）が独立した行として歌詞欄に挿入されます。歌詞欄が閉じている場合は自動的に展開され、カーソル位置を維持したままスムーズに入力を続けられます。
- **角括弧を省略したすっきりデザイン**: パレットのボタン上には `[ ]` を省略して中身のみを表示します（ボタン表示は `Verse 1`、挿入時は `[Verse 1]`）。
- **設定画面で自由に編集可能**: パレット右端の歯車アイコン（⚙）または設定ダイアログの **Lyrics Tags**（歌詞タグ）セクションから、登録タグを1行1タグ形式で編集・追加・削除・並び替えできます。いつでも「初期値に戻す」ボタンで初期リストへリセット可能です。

### スタイルとマスタリング

スタイルプルダウンは、**Style** / **Styles**（スタイル）の見出し直下に表示されるため、スタイルセクションの開閉状態に関わらず常に見えます。保存済みSunoスタイルと任意のマスタリングプロンプトを選択すると、拡張は両方を別の行としてスタイル欄へ入力します。**Manage…** / **管理…** から画面内ダイアログを開くと、マスタリングプロンプトの追加・編集・削除ができます。

拡張はSuno標準ダイアログから各保存スタイルのプロンプト本文だけを読み取り、永続保存しません。スタイル名は一覧のラベルに使われ、保存日はスタイル欄へ入力されません。Sunoの保存スタイル一覧を開く・変更した後は、次に拡張のプルダウンを開いた時点でメモリ上の一覧を更新します。

スタイルとマスタリングを合わせてSunoの1,000文字制限を超える場合は、何も変更せずエラーを表示します。

### 詳細オプションのプリセット

プリセットプルダウンは、**More Options** / **Other options**（その他のオプション）の見出し直下（開閉するパネル本文の手前）に表示されるため、パネルの開閉状態に関わらず常に見えます。スタイル除外、ボーカル性別、長さ、Maxモード、奇抜さ、スタイルの影響、バリエーション、パーソナライズのすべて、または選んだ項目だけを保存できます。

プルダウン右隣の **Save Preset** / **設定を保存** ボタンを押すと、Sunoの現在値を取り込んだプリセット作成ダイアログが開きます。スタイル除外、ボーカル性別、長さ、Maxモード、奇抜さ、スタイルの影響、バリエーション、パーソナライズから保存したい項目を選び、値を編集して保存してください。More Optionsが閉じていても設定を取得できます。また、プルダウン内の **Manage presets…** / **プリセットを管理…** から既存プリセットの編集や削除が行えます。適用時には、保存された設定だけが変更されます。

### 曲名の自動設定とテイク番号（{{TAKE}}）

曲名セクション内の **Auto title**（自動設定）を有効にすると、設定されたフォーマットに従って曲名を生成します。初期値は次の形式です。

```text
{{WORKSPACE}} ({{STYLE}}) {{TAKE}}
```

- 設定ダイアログの「Song Title Format」（曲名フォーマット）から任意の書式に変更できます。利用可能なプレースホルダ：
  - `{{WORKSPACE}}`: 保存先（ワークスペース名）
  - `{{STYLE}}`: スタイル名（選択スタイル名、手動編集時は `Custom` / `カスタム`）
  - `{{AUDIO}}`: 元曲名（リミックス・参照オーディオ設定時）
  - `{{TAKE}}`: テイク番号
- 曲名に `{{TAKE}}` が含まれている場合、**作成ボタンのクリック** または **ショートカット押下** 時に、現在の曲名（`{{TAKE}}` を除いたキー）に対応するテイク番号をローカルストレージでカウントアップし、テイク番号（1, 2, 3...）を入力してサブミットします。
- 送信後、曲名欄は即座に元の `{{TAKE}}` 入りテンプレートへ戻るため、続けて次のテイクを作成できます。
- 自動設定をオフにして手動で `My Song {{TAKE}}` と入力した場合でも同様にテイク番号がカウントアップされます。

### 作成ショートカットとひらめき表示

Suno作成画面では、設定不要で `Cmd + Enter`（macOS） / `Ctrl + Enter`（Windows/Linux）を押すと「作成」ボタンを実行できます（曲名に `{{TAKE}}` があればテイク番号採番・復元も行われます）。また、日本語UIでは操作行が折り返さないよう、Sunoの **インスピレーション** ボタンの表示を **ひらめき** に短縮します。

[拡張設定](images/suno_setting.png)

### サイドバー「拡張設定」メニュー

サイドバーのナビゲーション（Hooksの下・プロフィールの手前）に、歯車アイコン付きの **Extension Settings**（拡張設定）メニューを追加します。クリックするとSuno画面内の設定ダイアログが開き、曲名フォーマット、表示設定、マスタリングプロンプト、プリセットを一括管理できます。設定ダイアログが開いている間はメニューがアクティブ表示になります。また、サイドバーを最小化・折りたたんだ場合でも、Suno標準メニューと同様に文字が自動的に非表示になり歯車アイコンだけが綺麗に残るよう連動します。

### ディスクロージャの初期折りたたみ（表示設定）

アドバンスドタブを開いた際に、「歌詞」「スタイル」「その他のオプション（More Options）」の各入力セクション（アコーディオン）を閉じた状態をデフォルトにします。拡張機能のプルダウンUI（スタイル・マスタリング・プリセット）は見出し行に常に表示されているため、画面をすっきりと保ったまま素早く操作できます。

設定ダイアログ（サイドバーの「拡張設定」など）の「表示設定（Display Settings）」にある **「Close lyrics, styles, and more options when opening the Advanced tab」** / **「アドバンスドタブを開いた時に歌詞、スタイル、その他のオプションを閉じる」** チェックボックスから、この自動折りたたみ動作の有効／無効を切り替えられます（初期状態はON）。自動で閉じた後、個別のセクションを手動でクリックして開いた場合は、編集・入力中に勝手に再度閉じられることはありません。

## 開発・ソースコードからのビルド

ソースコードを変更して独自にビルド・開発を行いたい場合は、以下の手順に従ってください。

1. 依存関係をインストールします：
   ```bash
   pnpm install
   ```
2. 拡張機能をビルドします：
   ```bash
   pnpm build
   ```
   ビルド成果物は `install/chrome-mv3` に出力されます。
3. テストを実行する場合：
   ```bash
   pnpm test        # 単体テスト (Vitest)
   pnpm test:e2e    # E2Eテスト (Playwright)
   ```

## プライバシー

マスタリングプロンプト、プリセット、自動設定状態、曲名フォーマット、テイク番号の記録はすべてChrome拡張のローカルストレージに保存されます。Sunoの非公開APIは使わず、サーバーへのデータ送信や、Suno保存スタイルプロンプトの永続保存も行いません。
