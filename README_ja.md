# Suno Create Assistant

[Suno Create](https://suno.com/create) のアドバンストタブ向けローカルChrome拡張です。保存済みスタイルへの素早いアクセス、独自マスタリングプロンプト、再利用可能な詳細オプションプリセット、曲名の自動設定を追加します。

## ローカルへの導入

1. `pnpm install` で依存関係をインストールします。
2. `pnpm build` で拡張をビルドします。
3. `chrome://extensions` を開き、**デベロッパーモード**を有効にして、**パッケージ化されていない拡張機能を読み込む**から `output/chrome-mv3` を選択します。
4. `https://suno.com/create` を開き、**アドバンスト**タブを選択します。

## 使い方

### スタイルとマスタリング

Sunoのスタイル欄の下で、保存済みSunoスタイルと任意のマスタリングプロンプトを選択します。拡張は両方を別の行としてスタイル欄へ入力します。**管理…** から拡張オプション画面を開くと、マスタリングプロンプトの追加・編集・削除ができます。

拡張はSuno標準ダイアログから保存スタイルを読み取り、そのプロンプトを保存しません。Sunoの保存スタイル一覧を開く・変更した後は、次に拡張のプルダウンを開いた時点でメモリ上の一覧を更新します。

スタイルとマスタリングを合わせてSunoの1,000文字制限を超える場合は、何も変更せずエラーを表示します。

### 詳細オプションのプリセット

その他のオプション欄にプリセットプルダウンが追加されます。スタイル除外、ボーカル性別、長さ、Maxモード、奇抜さ、スタイルの影響、バリエーション、パーソナライズのすべて、または選んだ項目だけを保存できます。

**プリセットを管理…** を開き、Suno Createタブを表示した状態で **Sunoから現在値を取得** を使います。保存する設定を選んでプリセットとして登録してください。適用時には、保存された設定だけが変更されます。

### 曲名の自動設定

曲名入力の横にある **自動設定** を有効にすると、次の形式で曲名を生成します。

```text
保存先 (スタイル名)
```

設定はローカルに記憶されます。有効中は保存先とスタイル選択の変更に追従し、曲名欄は読み取り専用になります。手動編集したスタイル名は `カスタム` として扱います。

### 作成ショートカットとひらめき表示

操作行が折り返さないよう、Sunoの **インスピレーション** ボタンの表示を **ひらめき** に短縮します。拡張オプション画面の **ショートカットを設定** を選ぶとChromeのショートカット設定が開きます。**Sunoの「作成」を実行** に任意のキーを割り当ててください。既定のショートカットは予約しません。ショートカットは、現在開いているSuno作成タブ、または直近に操作したSuno作成タブで有効な作成ボタンを実行します。

## プライバシー

マスタリングプロンプト、プリセット、自動設定の状態はChrome拡張のローカルストレージに保存されます。Sunoの非公開APIは使わず、サーバーへのデータ送信や、Suno保存スタイルプロンプトの永続保存も行いません。
